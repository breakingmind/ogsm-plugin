# OGSM Profile Audit Questions

Use these questions to probe the internal logic of a written OGSM profile.
Ask each question in order. Record the user's answer or note if the profile answers it already.
Every unanswered or unsatisfactory question is a gap that must be flagged.

---

## O 最終目的（Objective）

| # | 問題 |
|---|------|
| O1 | 請問 O 的對象主要是要和誰說話？ |
| O2 | 請問 O 的範圍是什麼？ |
| O3 | 請問 O 的價值是什麼？ |
| O4 | 請問 O 的定位是什麼？ |
| O5 | 請問 O 的激勵人心之處（畫面感）在哪裡？為什麼？ |
| O6 | 請問 O 的關鍵字是什麼？ |

Passing criteria: O must name a target audience, scope, value, positioning, a vivid picture, and at least one keyword that Goals can trace back to.

---

## G 具體目標（Goals）

Repeat questions G7–G14 for each Goal. Replace "Goal X" with the actual Goal label.

| # | 問題 |
|---|------|
| G7  | 請問 Goal X 和 O 有對上嗎？為什麼？ |
| G8  | 請問 Goal X 對上哪個 O 的關鍵字？ |
| G9  | 請問 Goal X 的動詞是什麼？ |
| G10 | 請問 Goal X 的名詞是什麼？ |
| G11 | 請問 Goal X 的基準點是什麼？ |
| G12 | 為什麼 Goal X 設這個基準點？ |
| G13 | 請問 Goal X 的基準點是和什麼進行比較？ |
| G14 | 請問 Goal X 的總量為何？為什麼是這個總量？ |

Passing criteria: Each Goal must link to an O keyword, contain a verb, noun, baseline with comparison reference, and a total amount with justification.

---

## S 策略（Strategy）

Repeat questions S15–S20 for each Strategy. Replace "Goal：" and "資源(S)：" with the actual labels.

| # | 問題 |
|---|------|
| S15 | 請問這個 Strategy 對上哪個 Goal 的關鍵字？ |
| S16 | 請問這個 Strategy 和所屬的 Goal 都有對上嗎？ |
| S17 | 請問這個資源(S)：是以前從沒有過的？為什麼？ |
| S18 | 請問這個資源(S)：是獨特的嗎？為什麼？ |
| S19 | 請問這個資源(S)：會被消耗掉嗎？為什麼？ |
| S20 | 請問這個資源(S)：可以支撐所對應的 Goal 嗎？ |

Passing criteria: Each Strategy must link to a Goal keyword, and the resource/methodology/tool must be new or unique, consumable, and sufficient to support the Goal.

---

## M 檢核（Measure）

### MD 衡量指標（Dashboard）

Repeat questions M21–M24 for each MD item.

| # | 問題 |
|---|------|
| M21 | 請問衡量指標(MD)：有對上資源(S)：嗎？如何對上？是否活絡？ |
| M22 | 請問衡量指標(MD)：的目標是什麼？期望得到什麼結果？ |
| M23 | 請問衡量指標(MD)：可以向後追蹤到哪個 Goal 嗎？ |
| M24 | 請問衡量指標(MD)：有設定 deadline 和複查頻率嗎？ |

### MP 行動計畫（Action Plan）

Repeat questions M25–M28 for each MP item.

| # | 問題 |
|---|------|
| M25 | 請問行動計畫(MP)：有涵蓋到所對應的衡量指標(MD)嗎？ |
| M26 | 請問行動計畫(MP)：的負責人／人名是誰？ |
| M27 | 請問行動計畫(MP)：有時間序排列嗎？ |
| M28 | 請問行動計畫(MP)：目前的進度對衡量指標(MD)有沒有影響？ |

Passing criteria: Each MD must link to a Strategy and be traceable back to a Goal, with a deadline and review cadence. Each MP must have an owner, time order, and clear linkage to an MD.

---

## 整體向後追溯（Backward Logic）

| # | 問題 |
|---|------|
| B29 | 請問整體 M → S → G → O 可以完整向後追溯嗎？哪裡斷掉了？ |
| B30 | 還有其他需要補充或澄清的問題嗎？ |

Passing criteria: Every MP must trace back through MD → Strategy → Goal → Objective without any broken link.

## Scoring Integration

After completing all questions, map the answers to the dimensions in `review-rubric.md`.
Gaps found here directly lower the corresponding rubric score.
